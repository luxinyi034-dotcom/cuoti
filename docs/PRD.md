## 第 1 部分 · 第一版做什么（已确认）

设计稿：iPad I1–I5（主要）；手机 A、B、C、D、E1、F、G、H。

### 1.1 录入错题

- 拍照或手动输入；学科、我的答案、正确答案、为什么错（可多选：概念不清 / 审题不清 / 计算失误 / 粗心 / 方法不会 / 记忆错误）、提醒自己一句、知识点。
- 录入方式：**E1 一页填完（已确认）**。iPad 横屏左右两栏：左边照片 + 识别出来的题目 + 学科，右边答案、错因、提醒、知识点、来源、第一次复习时间（设计稿 I3）。
- 拍照识别文字用什么方式做，开始实现前再定。

### 1.2 错题本

- 按学科筛选、按掌握情况分段（全部 / 未掌握 / 已掌握）、搜索题目和知识点。
- iPad 横屏：左边列表、右边详情，点一道题右边直接显示（设计稿 I2）；竖屏只显示列表，详情从右边滑出。
- 列表里题干最多显示 2 行；详情页完整显示。

### 1.3 复习

- 先看题自己做，再看答案，自己选“还不会 / 有点会 / 掌握了”。
- 下次复习时间（初步）：还不会 → 明天；有点会 → 3 天后；掌握了 → 7 天后，再次“掌握了”间隔继续拉长。
- 做完给总结（设计稿 H）。

### 1.4 统计

- 掌握率、每天新增、错因分布、学科分布（设计稿 F）。

### 1.5 数据要求

- 数据只存在使用者自己的设备上，存储位置一旦定下永远不改；见项目根目录 `CLAUDE.md`。
- 每次升级前自动备份；能导出 / 导入备份文件。

### 1.6 第 1 部分验收标准（初稿）

1. 第一次打开看到设计稿 G 的引导，不出现任何假数据。
2. 录入一道题后，错题本、首页“最近错题”、统计都能看到它。
3. 复习时选择“还不会”，这道题第二天出现在今日复习里。
4. 在 iPad 横屏 1180×820、竖屏 820×1180 和手机 390×844 上截图检查，没有被遮住、被截断的内容。
5. 升级到新版本后，之前录入的错题、复习记录全部还在。

## 第 2 部分 · 手机版 v1（已实现）

设计稿：A、B、C、D、E1、F、G、H（手机）。代码：`site/index.html`。

### 2.1 和第 1 部分的差别

- 拍照不自动识别文字：照片和题目一起保存，题目文字可以不打（见待办第 3 条）。
- 首页快捷入口：拍照录入、手动录入、全部错题、备份（设计稿里的“扫描试卷”这一版不做）。
- 学科多一个“其他”。
- 录入页多了“解析（选填）”；草稿自动存，关掉再点“＋”能接着填。

### 2.2 一天怎么算

- 凌晨 4 点前算前一天（晚上学过 12 点，还算同一天）。所有地方都用同一个函数算“今天”。

### 2.3 复习安排

- 还不会 → 明天；有点会 → 3 天后；掌握了 → 7 天后，连续掌握依次 15、30、60 天后。
- “已掌握” = 最近一次选了“掌握了”。
- “再练一遍还不会的”只是练习，不改变复习安排。

### 2.4 数据要求

- 存储：IndexedDB 数据库 `cuoti-data`（错题、照片、自动备份），另在 localStorage `cuoti-data` 存一份文字副本。
- 自动备份：每天第一次打开、升级新版本前、删除 / 恢复 / 导入之前；每天的留 7 份，其他留 8 份。
- 导出备份文件（含照片）；7 天没导出在首页提醒一次，可以“过几天再说”。

### 2.5 第 2 部分验收标准

1. 第一次打开看到引导（设计稿 G），没有任何示例数据。
2. 录入带照片的题后，首页“最近错题”和错题本都能看到；关掉重新打开还在。
3. 第二天打开，首页显示“今天复习 N 题”；选“还不会”的第二天再出现，选“掌握了”的 7 天后再出现。
4. 删除要点两次；删之前自动备份，能在“我的”里恢复。
5. 导出的备份文件能导回来，照片也在。
6. 读不懂的数据原样另存，不被覆盖。
7. 旧版本的数据升级后全部还在，并有“升级到 v1 之前”的备份。
8. 手机 390×844 截图检查：对齐、不遮挡、长题目完整显示。

以上由 `tests/app.test.cjs` 自动检查（16 项）。

## 第 3 部分 · 拍照自动识别（v2，已实现）

设计稿：R1–R5（第 7 排）。使用者选了“用 AI 识别”。

### 3.1 用哪家

- 使用者在国外，打不开 open.bigmodel.cn，所以**默认用 Google Gemini**；智谱保留为“国内用”的选项，设置里一键切换，两家的密钥分开存。
- Gemini：网页直接调用 `https://generativelanguage.googleapis.com/v1beta/`（在开发环境实测过：允许 `luxinyi034-dotcom.github.io` 跨域；假密钥返回 `API_KEY_INVALID`，和 App 的判断一致）。模型名不写死：填密钥后调用 models 列表，自动选版本最新的 `gemini-X-flash`（正式版优先于 preview，不选 lite / pro）；模型下线（404）时自动重选一次。免费额度，不用绑卡。
- 智谱：`https://open.bigmodel.cn/api/paas/v4/chat/completions`，GLM-4.6V-Flash 免费，可换收费 GLM-4.6V。只能在国内用。
- 智谱国际版 z.ai 不能用：它的接口从 2026 年 9 月起不允许网页直接调用，至今没修（zai-org/feedback #590）。

### 3.2 规则

- 拍完照进入框选（R1，默认框住 90%）；“不识别，直接填”回到表单。设置里打开“拍完照自动识别”就跳过框选，识别整张。
- 识别时不挡住表单（R2）；结果只填进空着的格子（题目、我的答案、正确答案），不覆盖已经填的；学科只在你没手动选过时才改。
- AI 填的格子带“AI 识别”标记，改过就消失（R3）。
- 失败时（R5）分别说明：连不上 / 密钥不对 / 余额不足 / 免费版太忙 / 没认出题目；照片和已填内容都保留，可以“重新识别”。
- 编辑已存的题时不自动弹框选，可以手动点“识别照片里的题目”。

### 3.3 数据要求

- 用哪家、两家的密钥、模型、自动识别开关、每月识别张数存在 IndexedDB `cuoti-data` 的 `kv/ai`：不进错题数据，不进自动备份，不进导出的备份文件。
- 错题数据结构不变，v1 的数据直接能用。

### 3.4 第 3 部分验收标准

1. 填密钥后点“保存并测试”，显示“已连上，可以用”。
2. 拍照 → 框选 → 识别，题目、我的答案、正确答案、学科自动填好，有“AI 识别”标记。
3. 已经手写的格子，再识别也不会被改。
4. 断网、密钥错、太忙、认不出时都有对应说明，照片和已填内容还在。
5. 导出的备份文件里没有密钥。
6. 用 v1 录的题和照片，升级到 v2 后全部还在，并有“升级到 v2 之前”的备份。

以上由 `tests/app.test.cjs` 自动检查（共 20 项），Gemini 和智谱的回复是模拟的；**真实调用要在使用者手机上用真密钥确认**。

## 第 4 部分 · 识别改用 Claude（v3）

- 起因：使用者在国外，Google 只给 TA 的账号发 `AQ.` 开头的新格式密钥，调 Gemini（generativelanguage 和 Vertex 两个入口）都返回 401 `ACCESS_TOKEN_TYPE_UNSUPPORTED`。开发环境里用这把密钥实测过；论坛上大量同样报告，Google 没修。使用者选了 Claude（要充 5 美元）。
- 默认用 Claude，Gemini / 智谱保留为选项。设置里三选一：“Claude · 国外 / Gemini · 国外 / 智谱 · 国内”，各存各的密钥。
- 调用：Anthropic 官方 JS SDK（`@anthropic-ai/sdk@0.131.0`，打包成 `site/vendor/anthropic-sdk.mjs`，脚本 `scripts/build-anthropic-sdk.sh`），`dangerouslyAllowBrowser: true` 从网页直连 `api.anthropic.com`（实测允许跨域）。
- 模型：默认 `claude-haiku-5-5`（省钱，约 0.006 元 / 张），可换 `claude-opus-5-5`（最准，约 0.2 元 / 张）；`output_config.effort: low`，识别照片时用 `output_config.format` 的 JSON schema 保证返回格式；不传 temperature。
- 出错说明：密钥不对 / 余额不够 / 没权限 / 模型用不了 / 太快 / 太忙 / 连不上；Gemini 的 AQ. 密钥单独说明原因并建议换 Claude。
- 升级：v2 的数据和 AI 设置（已存的 Gemini 密钥、开关、张数）原样保留，只是多了 Claude。

验收：`tests/app.test.cjs` 22 项全过（含 v2 → v3 升级测试、Claude 识别和出错的模拟测试）；另用假密钥真实请求过一次 Claude，返回 401 并正确显示“密钥不对或过期了”。**用真密钥识别照片要在使用者手机上确认。**

## 第 5 部分 · iPad / 电脑版（v4）

设计稿：I1–I5（已确认）。同一个网址、同一份代码，按屏幕宽度自动换排版，数据规则不变。

- 宽度 < 700：手机排版（不变）。
- 700–899（iPad 竖屏）：左边只有图标的窄栏；首页从上往下排；错题本两列卡片，点开是详情页。
- ≥ 900（iPad 横屏、电脑）：左侧边栏（录入错题、首页、错题本、复习〈今天要复习几题〉、统计、我的、上次导出时间）；首页左右两栏；错题本左边列表、右边详情，点哪题右边换哪题，键盘 ↑ ↓ 切换；录入和复习左右两栏，侧边栏隐藏；统计、我的两列卡片。
- 转屏 / 改窗口大小时排版跟着变，不重新加载，正在填的内容不丢。
- 手机和 iPad / 电脑的数据各存各的（浏览器的限制），用“导出备份 → 导入备份”搬过去。

验收：`tests/app.test.cjs` 23 项（新增 1180×820、820×1180、1440×900 的排版测试，v3 → v4 升级测试）；截图自查过横屏首页 / 错题本 / 录入 / 复习 / 统计 / 我的、竖屏首页 / 错题本、电脑首页、手机各页。
