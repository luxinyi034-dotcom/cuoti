# 错题本 · 设计规范（v0.1 草案，待确认）

> 可视化版本：`docs/design/设计稿.html`（规范 + 9 张页面设计稿，同一份内容）。
> 参考图：`docs/参考图/参考图1-配色-咖啡App.jpg`（取配色）、`docs/参考图/参考图2-风格-磨砂玻璃.png`（取风格）。

## 1. 一句话风格

**一杯拿铁旁边的磨砂玻璃笔记本**：底色是奶油纸色，主色是浓缩咖啡深棕，强调色是焦糖；所有卡片是半透明的磨砂玻璃，浮在带柔光的暖色背景上；图标是细线条；整体安静、低饱和、留白多。

- 从参考图一拿的：配色（奶油底 + 深棕主按钮 + 焦糖强调字）、衬线大标题配问候语（“Good Morning, Isha” → “晚上好，今天复习 12 题”）、方形图标分类块、深棕色的选中态。
- 从参考图二拿的：磨砂玻璃卡片、细线图标、大圆角、柔和的环形进度和细折线图、底部导航中间一个圆形“+”按钮、背景里有光影层次而不是一块平色。

## 2. 颜色

所有界面只用下面这些变量，不写死颜色。

| 变量 | 色值 | 用在哪里 |
|---|---|---|
| `--paper` | `#F8F2EA` | 页面底色（奶油纸） |
| `--paper-2` | `#F1E7DB` | 第二层底色：输入框、未选中的分段按钮 |
| `--ink` | `#3A2519` | 主要文字（深咖啡） |
| `--warm` | `#7A6455` | 次要文字 |
| `--muted` | `#A8968A` | 辅助文字、占位文字 |
| `--line` | `#E6D8C8` | 细线、描边 |
| `--espresso` | `#4A2B1B` | **主色**：主按钮、选中状态、进度环 |
| `--espresso-ink` | `#FBF5EE` | 主色上面的文字 |
| `--caramel` | `#B5733A` | **强调色**：问候语第二行、大数字、文字链接 |
| `--caramel-soft` | `#F1E0CC` | 错因标签底色、图表面积 |
| `--latte` | `#D8BC9C` | 图表次要数据、背景光斑 |
| `--wrong` / `--wrong-soft` | `#B0503A` / `#F5E1D8` | **只表示“答错了”**：我的错误答案、“还不会” |
| `--right` / `--right-soft` | `#6B7A52` / `#E6E9D9` | **只表示“对的 / 掌握了”**：正确答案、已掌握 |
| `--glass` | `rgba(255,250,244,.58)` | 磨砂玻璃卡片底 |
| `--glass-strong` | `rgba(255,251,247,.78)` | 需要更清楚的玻璃（底部导航、弹层） |
| `--glass-edge` | `rgba(255,255,255,.75)` | 玻璃卡片的亮边 |

三条底线：

1. **红色只表示“答错”**，不用来做装饰、不用来表示“重要”。
2. **学科不分颜色**：数学、物理、英语……都用同一色系，靠**图标 + 名字**区分。颜色一多就花，统一色系才耐看。
3. **一屏只有一个深棕色实心主按钮**，其他按钮是玻璃描边或文字按钮。

## 3. 字体

| 角色 | 字体 | 字重 / 字号 / 行高 | 例子 |
|---|---|---|---|
| 大标题 | Noto Serif SC（思源宋体） | 600 · 26 / 34 | 晚上好，今天复习 12 题 |
| 小标题 | Noto Sans SC（思源黑体） | 600 · 15 / 22 | 最近错题 |
| 正文、题干 | Noto Sans SC | 400 · 13.5 / 22 | 解不等式 \|2x−1\| < x+1 |
| 辅助文字 | Noto Sans SC | 400 · 11.5 / 16，`--muted` | 下次复习 · 明天 |
| 数字、英文、公式 | Fraunces | 300–400 · 按场景 | 61%　5 / 12　x² |

- 大数字用 Fraunces 细体（300），像参考图二里的“76%”“2h 45m”。
- 题目里的英文句子和公式用 Fraunces，读起来像试卷。
- 长题干不截断：列表里最多显示 2 行，详情页完整显示、自动换行。

## 4. 形状、质感、间距

- **圆角三档**：12（标签、输入框、小方块）· 18（卡片）· 26（大卡片、弹层）；按钮和标签用全圆角胶囊；手机外框 46。
- **磨砂玻璃卡片**（默认卡片）：`--glass` 底 + 背景模糊 18px + 1px 亮边 `--glass-edge` + 顶部一条内高光 + 很淡的暖棕色投影（`0 16px 34px -18px rgba(74,43,27,.35)`）。
- **实色只给主按钮**：深棕实色 + 一点下投影。
- **背景**：不是平色。奶油底上叠两三块柔和的拿铁色、白色光斑，模拟参考图二的光影，让玻璃有东西可以“透”。
- **细线**：1px `--line`；分隔线尽量少，靠留白分组。
- **间距**：4 / 8 / 12 / 16 / 24 / 32。页面左右边距 18，卡片内边距 14–16，卡片之间 12。

## 5. 图标

- 24×24 格子，**1.6 线宽**，圆头圆角，只用线性图标，不用填色图标、不用 emoji。
- 选中时图标所在的小方块变成深棕底、图标变奶油色，而不是换一种颜色。
- 学科图标：数学 ∑ · 物理 原子 · 英语 Aa · 化学 烧瓶 · 语文 书卷。
- 动作图标：拍照、手写、扫描、搜索、筛选、复习（循环箭头）、解析（灯泡）、备份（云）。

## 6. 组件

| 组件 | 规则 |
|---|---|
| 主按钮 | 高 46，胶囊，深棕底、奶油字；一屏一个 |
| 次按钮 | 高 46，胶囊，`--glass-strong` 底 + `--line` 描边 |
| 文字按钮 | 焦糖色文字，比如“查看全部”“保存” |
| 圆形图标按钮 | 38×38 玻璃圆，用于返回、通知、更多 |
| 学科方块 | 60×66，图标在上、名字在下；选中 = 深棕底（参考图一的分类块） |
| 错因标签 | 胶囊，`--caramel-soft` 底，深焦糖字；可多选 |
| 分段按钮 | 一条玻璃底，选中段是奶油白实底 + 轻投影 |
| 输入框 | 高 44，圆角 12，`--paper-2` 底，无描边；聚焦时 1px 焦糖描边 |
| 掌握度 | 三个小圆点：还不会 ●○○ · 有点会 ●●○ · 已掌握 ●●● |
| 进度环 | 细环（线宽 6），深棕进度 + `--line` 底环，中间 Fraunces 细体数字 |
| 底部导航 | 玻璃浮条，五格：首页 · 错题本 · ＋录入（深棕圆形）· 统计 · 我的 |
| 答案对比块 | “我的答案”用 `--wrong-soft` 底 + ✕；“正确答案”用 `--right-soft` 底 + ✓ |

## 7. 文案语气

- 短句、口语、说清楚点了会怎样：“开始复习”“保存，明天复习”“再练一遍还不会的”。
- 不说教，不用感叹号堆情绪；空的时候告诉下一步做什么：“拍下一道做错的题，几秒就能记下来”。
- 会删除东西的按钮点两次确认，并说明后果：“再点一次，删除这道错题”。

## 8. 屏幕尺寸

设计稿先按手机竖屏 390×844 画（画布里按比例缩小显示）。**待确认：你主要在手机上用还是 iPad 上用？** 确认后每次都在那个尺寸截图自查。
