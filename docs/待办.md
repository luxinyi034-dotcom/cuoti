## 3. 拍照自动识别文字（2026-10-20，使用者主动提出想要）

- v1 里照片和题目一起保存，题目文字要自己打（有照片可以不打）。
- 试过手机上的识别方式（Tesseract 中文模型，约 1.7 MB）：印刷体中文基本都对；公式、上下标、负号会错（m/s² → m/sz，HNO₃ → HNOa，2x−1 → 2x01）；手写基本认不出。字和字之间会多出空格，要自动去掉。
- 两种做法等使用者选：
  - A 手机上识别：免费、照片不上传、没网也能用（第一次要下载约 6 MB）；公式要手动改。
  - B 用 AI 识别：公式、上下标都能认，还能自动分出题目 / 我的答案 / 正确答案；要 API 密钥，每张照片要花一点钱，照片会上传。
- 不管选哪种，都先画设计稿：拍完照框选题目区域 → 识别中 → 识别结果填进“题目”可以改。
